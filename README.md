A chess engine in 4,033 bytes of Python: negamax alpha-beta search with a
transposition table, quiescence, null-move pruning and late move reductions,
a tapered piece-square evaluation with passed pawns, and a fixed node
budget (never a clock), so every game replays move for move.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
